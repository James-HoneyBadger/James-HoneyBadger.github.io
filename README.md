# James HoneyBadger · GitHub Pages

Two views:

- `index.html` — pinned repositories from the GitHub profile, ordered by stars (desc). This page reads from `data/pinned.json`.
- `repos.html` — searchable, sortable list of every public repo under `@James-HoneyBadger`, powered by the GitHub REST API.

## Keeping pinned repos in sync

Pinned repos are generated by a scheduled GitHub Action: `.github/workflows/update-pinned.yml`.

- Run it manually once from the Actions tab (Workflow dispatch), or wait for the schedule.
- If the workflow fails to read pinned items, add a fine-grained PAT as a repo secret named `PINNED_REPOS_TOKEN`.
