# James HoneyBadger · GitHub Pages

Two views:

- `index.html` — highlights ONLY pinned repositories from `@James-HoneyBadger` (and only repos owned by that account), ordered by stars (desc). Uses `hb.jpg` on the homepage.
- `repos.html` — searchable, sortable list of repositories owned by `@James-HoneyBadger` (forks excluded), powered by the GitHub REST API.

Both pages share `styles.css` and are rendered entirely in the browser, so they need JavaScript enabled.

## Keeping pinned repos in sync

Pinned repos are generated by a scheduled GitHub Action: `.github/workflows/update-pinned.yml` (every 6 hours, and on demand).

- Add a repo secret named `PINNED_REPOS_TOKEN` (classic PAT with `read:user` is simplest).
- Run the workflow once (Actions → "Update pinned repos" → Run workflow).

The generator skips the write when the pinned data is unchanged, so a quiet run produces no commit
and no Pages rebuild. `generatedAt` only moves on runs that actually change something.

Running it locally:

```bash
GITHUB_TOKEN=<token> node scripts/update-pinned.mjs
```

Overrides: `GH_PINNED_USER` (default `James-HoneyBadger`) and `GH_PINNED_OUT` (default `data/pinned.json`).
