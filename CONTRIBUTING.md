# Contributing to James-HoneyBadger.github.io

This is an independently maintained Honey Badger project. Small, evidence-backed fixes are welcome; no support or review timetable is promised.

- Start with the README and existing documentation; use the canonical repository at https://github.com/James-HoneyBadger/James-HoneyBadger.github.io.
- Fork and branch from the default branch. Describe the problem, reproduction, expected result and affected platform.
- Keep public-only, owned-repository filtering intact. Do not commit private repository data; use the existing data generator and validator. Check both themes, no-JavaScript fallback and shareable filters.
- Include a regression test where practical; report commands actually run, their results and any skipped checks. Update documentation with behavior changes; do not claim untested support.
- Avoid secrets, personal records and third-party material without redistribution rights. Respect existing license and provenance notices.
- Open a focused pull request. Formal releases remain a separate maintainer decision.

If maintenance pauses, the documented build and test path and repository history are the starting points for an independent fork, subject to applicable licenses.
